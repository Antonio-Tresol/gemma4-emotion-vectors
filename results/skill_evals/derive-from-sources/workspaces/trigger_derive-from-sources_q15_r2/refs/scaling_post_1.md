# Scaling laws blog post 1: compute-optimal training is misunderstood

Saved from the web, 2026-07-10.

This post argues that compute-optimal training is misunderstood. The author walks through the Chinchilla
compute-optimal framing, then claims that data quality shifts the exponent
more than most replications assume.

Key argument: loss curves alone under-determine the story; downstream task
scaling can diverge from loss scaling by a wide margin.

Takeaway: treat published scaling exponents as dataset-specific, not universal.
