# self_stories_it

third-person stories generated by the probed model itself, 12 battery emotions (E6 scale corpus; leakage ~1% at pilot QC)

Generated by [cbai-cambria-project](https://github.com/Antonio-Tresol/cbai-cambria-project) `scripts/generate_dialogue_stories.py` (instruction includes 'do not name the emotion'; leakage QC in the research log). Files: `dialogues_raw.jsonl` (one row per text), `dialogues_grouped.jsonl` ({emotion, stories} rows, the extraction pipeline's input), `generate.log`.
