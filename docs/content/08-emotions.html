7Some emotions are followed well, others not at all

For every phase of every story, we measured the centred cosine against all twelve emotion vectors. The question is how often the winner is the emotion that phase was written to convey.

The set shifts here from 171 emotions to twelve, because the stories were written to move between these twelve. Picking at random would be right 1 time in 12, or 8%. Each bar is one emotion's score.

The two buttons swap in a different set of emotion vectors, built from a different writer's stories, the same swap as section 2. The layer buttons read the same measurement at a different depth of the model. Hover any bar to see where its wrong answers went.

The twelve-emotion vector sets exist only for the instruction-tuned model. An emotion vector has to be built from stories, and these were built from stories that model wrote about itself. Running the same test on the base model would mean rebuilding all twelve vectors from base-model stories, which we did not do. This section therefore covers the instruction-tuned model only.

At layer 33, with vectors from Gemma's own stories, 11 of the 12 emotions beat chance. Nothing reaches 50%, and the spread is wide: loving and guilty win about half the time, while nervous sits below chance at 5.8%. Changing the layer shuffles the order.

The wrong answers pile onto two emotions: with Gemma's own vectors, whatever the true answer was, the model keeps replying guilty or happy. With DeepSeek's vectors that pile-up disappears and overall accuracy rises. So the vectors we handed the model account for a real share of what looks like a failure to follow emotions.

TakeawayThe model follows emotion better than chance, but unevenly and never reliably. A large part of that unevenness comes from the emotion vectors themselves: swap in a different writer's vectors and both the accuracy and the pattern of mistakes change.
