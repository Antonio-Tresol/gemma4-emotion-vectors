This second measurement uses no principal components, so it cannot inherit an artefact of that decomposition. A model has many layers, stacked from input to output. At each layer we recorded which emotions the model treats as similar to which, which gives one emotion-by-emotion similarity table per layer. How to read this

What a good result looks like: dark everywhere. That is a model whose layers all agree on what emotions are, one stable picture from bottom to top. What a bad result looks like: pale patches and visible blocks. Groups of layers agree with each other but not with the rest, so the model has no single account of emotion.

Every square is scored from 0 to 1: 1 means the two layers sort the 171 emotions identically, 0 means they share nothing. Start on base model and you get close to the good case: its late layers agree with each other at 0.94 out of 1. Now switch to instruction-tuned model. The same measure drops to 0.79 and the grid visibly breaks into blocks. The base view matters here as the control: without it, you could not tell a genuinely broken-up model from a measure that just always looks blotchy.

Now switch to instruction-tuned, top PC removed. We remove just the biggest axis at each layer, and the blocks largely merge back together. That is the evidence that the one dominant axis caused the fragmentation, rather than the emotion structure having gone missing.

base vs. instruction-tuned is the odd one out. It is the only view with a different model on each axis, and so the only one that is not a mirror image about its diagonal. Rows are instruction-tuned layers, columns are base layers, and the diagonal answers "how much did instruction tuning change this particular depth?". If instruction tuning changed nothing the diagonal would read 1.0 throughout. It reads 0.97 at layer 3 and 0.21 at layer 57: the early layers came through intact, the late half was rebuilt.

The caveat that cuts the other way Taken at face value, the two models look largely unrelated. Comparing each model's top three axes as a set gives three angles, 86.1°, 56.0° and 46.1°, where 90° means two directions share nothing and 0° that they coincide. The widest is almost a right angle; even the closest pair is only partly aligned. But subtract that one unidentified axis and the late layers of the two models jump from 0.29 agreement to 0.60, on the same 0-to-1 scale as the grid above. So the shared emotion structure is not gone. It is sitting underneath one large direction that has nothing to do with emotion.
TakeawayThe biggest thing separating emotions in the instruction-tuned model is not a rearrangement of anything the base model had. It is new, instruction tuning put it there, and it breaks the model's layers into disagreeing blocks. We can show all of that. We still cannot say what it encodes.
